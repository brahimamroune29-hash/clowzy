# البحث اليدوي والبحث بمساعدة AI

طلب المستخدم الأخير: الاستمرار بالإصدار الحديث، وإتاحة طريقتين منفصلتين للبحث، وتنفيذ الخطة مباشرة دون انتظار موافقة جديدة على التصميم.

## خطة التنفيذ

1. صفحة `/search` لاختيار الطريقة بالتساوي: بحث يدوي أو بمساعدة AI.
2. المسار اليدوي `/search?method=manual`: الحقول ظاهرة؛ اختيار المجال والتخصص والدول والمدينة والمسمى والحجم. ملخص العدد والرصيد بجانبها.
3. مسار المساعد `/search?method=ai`: وصف طبيعي ومتابعة وملخص قابل للتعديل؛ لا يفرض نفسه على المستخدم اليدوي.
4. الانتقال بين المسارين يحفظ المعايير والعدد، ويلغي تأكيد البدء حتى يراجع المستخدم الاختيارات. الوصف غير المرسل لا يمنع بدء بحث يدوي تمت مراجعته.
5. روابط البحث المحفوظ/المكرر تفتح المسار اليدوي، وروابط المساعد تفتح مسار AI. لا تغيير في جلب البيانات أو خصم الرصيد أو CRM.
6. فحص الخيارات، حفظ المعايير عند التنقل، اللغتين، الهاتف، وبناء نسخة الإصدار المعزولة. إعادة فحص صلاحية Vercel بالطريقة الرسمية؛ لا تغيير لهوية مؤلف الكود أو إخفاء معلومات Git.
